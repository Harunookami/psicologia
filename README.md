# Landing page para psicóloga clínica

Este é um projeto de estudo de uma landing page para uma psicóloga clínica. A página está sendo construída do zero, em fases, com base em um protótipo visual criado no Figma Make.

## Tecnologias

- **React**: biblioteca usada para construir a interface.
- **React DOM**: integração dos componentes React com o DOM do navegador.
- **TypeScript**: tipagem e desenvolvimento dos arquivos `.ts` e `.tsx`.
- **Vite**: servidor de desenvolvimento e ferramenta de build.
- **ESLint**: análise estática e verificação de padrões no código.
- **@vitejs/plugin-react**: integração do React com o Vite.
- **typescript-eslint**: integração do TypeScript com o ESLint.

## Como rodar localmente

### Pré-requisito

- [Node.js](https://nodejs.org/) instalado.

### Instalação

1. Clone o repositório:

   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd psicologia
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

O Vite exibirá no terminal o endereço local para acessar a aplicação.

## Estrutura de pastas

```text
src/
├── App.tsx                 # Componente principal da aplicação
├── main.tsx                # Ponto de entrada que renderiza a aplicação
├── components/             # Componentes reutilizáveis da interface
│   └── Header.tsx          # Arquivo do componente de cabeçalho
├── data/                   # Espaço reservado para dados usados pela interface
├── sections/               # Espaço reservado para seções da landing page
└── styles/                 # Estilos globais e variáveis visuais
    ├── global.css
    └── variables.css
```
